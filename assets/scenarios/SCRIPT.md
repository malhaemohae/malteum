# 시연 시나리오 스크립트 (TTS 제작용)

심사위원은 배포 URL 에 접속해 마이크 없이 서비스를 본다. 그래서 상담 음성을 TTS 로 미리 만들어 두고, 그 음성 파일 하나를 서버로 흘려 STT 부터 판정까지 실제 경로를 태운다. 이 문서는 그 음성의 대본이고, 옆의 `preset-*/script.json` 이 같은 내용의 기계용 사본이다.

팀 합의(2026-09-02) 로 정한 제작·재생 방식은 다음과 같다.

| 단계 | 담당 | 입력 → 출력 |
| --- | --- | --- |
| 대본 | M3 (이 문서) | `script.json` 의 `lines[]`. 줄마다 화자·시각·대사·TTS 발음용 문장·기대 판정 |
| TTS | R5 | 줄마다 클립 하나(`<id>.wav`). 화자별로 다른 음성 |
| 조립 | R5 | 클립을 `start_ms` 타임라인대로 이어 붙여 **단일 파일** `audio.wav` (16kHz · mono · PCM16) |
| 재생 | M1 서버 | `audio.wav` 를 실시간 속도로 STT 에 스트리밍(`replay` 모드) |
| 화자 | M1 서버 | STT 의 화자 분리(diarization: 목소리 차이로 "누가 말했나" 를 구간별로 나누는 기능) 결과를 `teller`·`customer` 로 매핑 |

화자 분리와 매핑은 서버 담당 몫이다. 이 문서는 대본과 조립 규격까지만 정한다. 두 문서는 함께 고친다. 대사를 바꾸면 `script.json` 의 `text`·`tts_text`·`expect` 를 같이 바꾸고, 4장의 검증 방법으로 다시 돌려 본다.

| 프리셋 | 팩 | 길이 | 장면 |
| --- | --- | --- | --- |
| `preset-dep-a` | `DEP-2026.08-v4` (ICBC 원화정기예금) | 3분 15초 | 정기예금 중도해지 상담. 기본 시연 경로 |
| `preset-loan-b` | `LOAN-2026.08-v3` (하나은행 가계 신용대출) | 3분 | 신용대출 금리·한도 안내. 심화 경로 |

모든 인물은 가상이다. 화면에 "시연 시나리오" 표시를 상시 띄운다(기획 16장 리스크 4).

## 1. 대본이 화자 분리를 돕기 위해 지킨 것

서버가 목소리로 화자를 가르는 만큼, 대본 쪽에서 실수 여지를 줄였다.

| 규칙 | 이유 |
| --- | --- |
| 은행원은 남성, 고객은 여성 음성 | 목소리 차이가 클수록 화자 분리가 정확함 `[관례]` |
| 화자가 바뀌는 자리마다 무음 1초 이상(`audio.min_gap_ms`) | 두 화자의 말이 붙으면 STT 가 한 발화로 합쳐 내고, 그러면 문장 단위로 갈라도 화자가 섞임 |
| 같은 화자가 연속으로 말하는 줄은 `speaker` 열이 진실 | 화자 분리 결과와 대조할 때 쓰는 정답. `diarization_hint.turn_order` 참조 |
| 첫 화자는 두 시나리오 모두 고객 | 서버가 "첫 화자 번호 = customer" 같은 단순 규칙을 쓸 수 있게. `diarization_hint.first_speaker` |
| 고객 대사는 되물음 장면 외에 물음표로 끝내지 않음 | 4.2 참조. 화자가 고객으로 제대로 잡혀야 이 규칙이 뜻이 있음 |

**화자 매핑이 틀리면 무엇이 깨지나.** 위험 신호(`risk`)와 되물음(`comprehension`)은 고객 발화만 보고([tiers/l1/gate.py](../../back/engine/tiers/l1/gate.py)), 필수 고지와 금지 발언은 은행원 발화만 본다. 고객 줄이 은행원으로 붙으면 2:55 의 위험 신호 경보가 사라지고, 반대면 은행원의 고지가 미고지로 남는다. 그래서 `script.json` 의 `speaker` 열을 서버 쪽 회귀 테스트의 정답으로 쓰길 권한다.

## 4. 검증 방법과 실측 기록

### 4.1 엔진 통과 실측 (2026-09-02)

두 `script.json` 의 대사를 서버의 문장 분리(`server/services/stt/assembler.py` 의 `utterances`)를 거쳐 실제 엔진(L0 → L1 → L2, `intfloat/multilingual-e5-small` 임베더, LLM 없음)에 순서대로 넣고 상태를 이어 가며 판정을 봤다. STT 를 거치지 않은 정답 전사와 정답 화자 기준이다.

| A 금지 발언 L2 예시 유사도 | "만기 지나도 금리가 그대로 유지되니까 그냥 두셔도 돼요" 0.76 (임계 0.5). 앞 초안 "만기 지나도 지금 금리가 그대로 계속 붙거든요" 는 0.57 이라 여유가 적어 교체 |
| A 위험 신호 | L1 정규식(`딸이 알려준`) 적중, critical |
| A 숫자 | 0.5% → 경보, 0.1% → 경보 없음. `0.5 퍼센트` 표기도 같은 결과 |
| B 종료 상태 (v2 팩) | met 4 (`INT`·`PRE`·`ARR`·`WDR`, L1) · `BAN-001`·`RSK-001` suspected(L1) · unmet `DSR`(L3 몫)·`CIC` |
| B 종료 상태 (v3 팩) | met 6 (`DSR`·`ARR-002` 포함, 전부 L1) · 0:25 되물음에 `DSR` 재진술 카드 · 2:13 의 3% 에 경보 없음 · `BAN-001`·`RSK-001` suspected(L1) · unmet `CIC` |

재현: 스크립트는 세션 스크래치에만 있고 레포에 넣지 않았다. 필요하면 `back/scripts/eval_l2_goldenset.py` 를 본떠 `engine.build.build_engine(FilePackSource, LocalStEmbedder(), MemoryVectorIndex())` 로 엔진을 만들고 `judge`·`apply` 를 대사 순서대로 부르면 같은 결과가 나온다.

### 4.2 대사를 쓸 때 지킨 규칙 (실측에서 나온 것)

| 규칙 | 이유 |
| --- | --- |
| 고객 대사는 되물음 장면 외에 **물음표로 끝내지 않는다** | 엔진 기본 되물음 패턴에 `\?\s*$` 가 있어, 물음표로 끝나는 고객 발화는 전부 되물음으로 잡히고 이미 설명된 항목 중 하나에 재진술 카드가 붙는다 |
| "네?" 를 **독립 문장으로 두지 않는다** ("네에, …" 로 이어 쓴다) | 서버가 `?` 뒤에서 문장을 나누므로 "네?" 만 따로 판정된다. 유사도가 전부 0 인데도 되물음 대상이 첫 항목으로 잡혀 엉뚱한 재진술 카드가 떴다(실측) |
| 은행원 대사 한 문장에 **한 항목만** 담는다 | 서버가 마침표 단위로 나눠 판정한다. 한 문장에 두 항목을 넣으면 한쪽 요소가 모자라 partial 이 되거나 L1 을 건너뛴다 |
| 요소가 하나뿐인 키워드 언급은 판정되지 않는다 | `matcher.required_verdict` 가 요소 1개짜리 일반 키워드 히트를 "주제 언급" 으로 보고 넘긴다. met 을 원하면 요소 2개 이상을 한 문장에 |
| partial 을 남기려면 요소를 **정확히 하나** 빼고 말한다 | `PRO-001` 은 '합산'·'합쳐'·'합해' 중 하나가 들어가면 met 이 된다. 그래서 "원금과 이자 포함" 으로 썼다 |
| 정정 문장에서 금지 예시의 단어를 다시 쓰지 않는다 | "상환방식은 고객님이 선택하실 수 있습니다" 는 금지 예시와 0.66 겹쳐 재경보 위험. "갚는 방법" 으로 바꿨다 |

### 4.3 TTS 제작과 조립 지침

| 항목 | 내용 |
| --- | --- |
| 클립 | 대사 한 줄에 파일 하나(`<id>.wav`). `tts_text` 가 있으면 그것을 TTS 에 넣고, 없으면 `text` 그대로 |
| 음성 | `speakers` 의 설명대로 은행원 남성·고객 여성. 두 시나리오의 은행원은 같은 음성 |
| 숫자 발음 | "영 점 오 퍼센트"·"일억 원"·"디에스알"·"십사 일" 처럼 STT 가 숫자·용어로 되돌리기 쉬운 발음으로 `tts_text` 에 적었다 |
| 조립 | 클립을 `start_ms` 에 놓아 하나의 `audio.wav` 로 만든다. 앞 클립이 아직 안 끝났으면 앞 클립 끝 + `min_gap_ms`(1초) 에 놓고 이후 줄을 같은 만큼 민다. 조립 결과의 실제 시작 시각을 `script.json` 에 `actual_start_ms` 로 적어 두면 서버 쪽 대조에 쓸 수 있다 |
| 출력 규격 | 16kHz · mono · PCM16 WAV. 계약 `audioFrame` 규격이고 서버가 다른 규격을 거절한다(`stt/audio.py`) |
| 위치 | `assets/scenarios/<preset_id>/audio.wav`. git 에는 넣지 않는다(`assets/README.md`) |
| 여백 | 경보 카드 뒤(A 0:30, 1:15 / B 0:57, 1:30) 는 심사위원이 읽을 시간으로 10초 이상 비워 두었다 |
| 공급자 | 미결(기획 19장). 생성 음성의 상업적 사용 약관을 확인한다 |

### 4.4 STT 사전 점검 (조립된 음원이 나오면 반드시)

`back/scripts/stt_check.py` 가 재는 방식 그대로, 조립된 `audio.wav` 를 Deepgram 에 흘려 아래가 전사에 그대로 나오는지, 그리고 줄마다 화자가 `script.json` 의 `speaker` 와 같은지 본다. 하나라도 어긋나면 그 줄의 판정이 통째로 빠진다.

| 줄 | 전사에 있어야 하는 것 | 없으면 |
| --- | --- | --- |
| 전체 | 줄마다 화자 번호가 `speaker` 열과 일관되게 대응 | 고객 줄이 은행원으로 붙으면 위험 신호·되물음이 사라짐 |
| A 0:12 | `우대이자율` `기본이자율` (붙여서) | `INT-001` 미고지 |
| A 0:30 | `0.5%` 또는 `0.5 퍼센트` | 숫자 경보 없음 |
| A 0:45 | 문장 끝 `?` | 되물음 미검출 → 재진술 카드 없음 |
| A 1:50 | `중도해지이율` `0.1%` | partial 갱신 없음 |
| A 2:02 | `중도해지이율` `차감률` | `INT-002` 가 partial 로 남음 |
| A 2:40 | `예금자보호` `1억` (숫자 1) | "일억" 으로 오면 한도 요소가 빠져 partial 도 안 되고 L3 몫이 됨 |
| A 2:55 | `딸이 알려준 계좌` + 화자 customer | 위험 신호 미검출 |
| B 0:12 | `DSR` 또는 `총부채원리금상환비율` | `DSR-001` 미고지 |
| B 2:13 | `연체가산이자율` `3%` | `ARR-002` 미고지, 숫자가 다르게 오면 오경보 |
| B 0:57 | `무조건 승인됩니다` | 금지 발언 미검출 |
| B 1:30 | `다른 상환방식은 안` | 금지 발언 미검출 |

keyterm 은 팩의 `jargon_terms` 를 서버가 자동으로 넣는다(`ws/endpoint.py` 의 `_start_stt`). `차감률`·`중도해지이율` 이 keyterm 에 있어 붙여 쓴 전사가 나올 확률이 높지만, 실측 전까지는 가정이다.

## 5. 알려진 제약

| 제약 | 내용 | 영향 |
| --- | --- | --- |
| 화자 분리 | 서버가 STT 화자 분리 옵션을 켜고 번호를 `teller`·`customer` 로 매핑해야 한다. 현재 서버는 오디오 경로의 화자를 전부 `teller` 로 고정(`stt/session.py`) | 서버 작업 전에는 고객 줄의 위험 신호·되물음이 뜨지 않음 |
| L3 의존 | 넛지, violated 확정, comprehension confirmed 는 LLM 심판이 붙어야 나온다 | `APP_LLM_MODEL` 이 비면 그 장면이 빠진다. 배포 전 확인 |
| 재진술 채택 기록 | 엔진은 은행원이 카드를 따라 말했는지(`outcome=adopted`) 를 판정하지 않는다. fixture 에만 있는 값 | 화면의 "채택" 표시는 뜨지 않음 |
| 용어 밀도(⑧) | 엔진에 구현이 없다(`term_density` 를 계산하는 코드 없음) | 시연에서 보여줄 수 없음 |
| 대출 팩 | 주담대가 아니라 신용대출 팩. 금리인하요구권·서류 항목은 검토 대기로 미발행. 숫자 사실은 3년·연 3% 둘뿐(청약철회 14일은 근거 chunk 가 달라 못 실음) | B 는 기획 9장 B 표의 금리인하요구권·서류 장면을 담지 못함. ⑤ 는 2:13 대사를 틀리게 바꾸면 가능 |
| 대출 팩 버전 | v3 이 `contracts/fixtures/` 에 있어 서버가 파일로 읽을 수 있음. DB 에 v2 가 적재돼 있으면 `POST /sessions` 에 `pack_version: LOAN-2026.08-v3` 을 명시해야 함 | v2 로 열면 3장의 기대 판정과 어긋남 |

| 서버 프리셋 | `GET /presets` 가 빈 목록을 돌려주고 기본 팩이 `DEP-2026.08-v4` 하나 | B 를 열려면 `POST /sessions` 에 `pack_version` 과 `audio_ref` 를 넘겨야 함 |
