# 상담 동선·상세 단계 축소

대상: `front/` UI. 서버 계약·판정·기록 의미는 변경하지 않음.

## 바뀐 경로

클릭 수는 해당 시작 화면에서 항목이 보이는 경우를 기준으로 한다. 목록의 페이지 이동, 응답 대기, 필수 입력은 별도다.

| 시작 위치 / 작업 | 이전 | 변경 후 |
| --- | --- | --- |
| 필수 안내 / 쉬운 말 | 항목 상세 → 재진술 요청 | 행의 **쉬운 말** 1회 → 결과 |
| 필수 안내 / 수동 고지·취소 | 항목 상세 → 기록·취소 | 행의 **고지 기록·기록 취소** 1회. 서버 확인 뒤 반영 |
| 필수 안내 / 근거 | 항목 상세 → 근거 → PDF 탭 | 행의 **근거** 1회. 데스크톱에서 인용문과 PDF 동시 표시 |
| 상세·쉬운 말 결과 / 근거 | 상세창 위에 근거창 추가, 두 번 닫기 | 근거창 하나만 유지. 닫으면 상담 화면 |
| 쉬운 말 결과 재확인 | 항목을 다시 찾아 요청 | 피드백의 **쉬운 말 보기**. 새 요청 없이 마지막 응답 열기 |
| 종료 리포트 / TRACE | 이력으로 이동 → 해당 상담 찾아 재생 | 리포트의 **TRACE 재생** 1회 |
| 문서 검수 / 문서 전환 | 문서 목록으로 복귀 → 다른 문서 선택 | **검수 문서 바로 선택**에서 전환 |
| 기준 관리 복귀 | 항상 규정 팩 탭부터 진입 | 마지막 작업 탭(규정 팩/문서 검수) 복원 |
| TRACE 원본 선택 / 첫 발화 확인 | 선택창 위에 첫 발화창 중첩 | 같은 창에서 미리보기·바로 재생·목록 복귀 |
| 추출 표 / 셀 원문 | 추출창 위에 셀 원문창 중첩 | 같은 창에서 셀 원문과 표 전환 |
| 종료 후 / 새 상담 | 상품·유형·입력 방식 다시 설정 | 직전 실제 상담 설정 유지. 모바일 리포트/이력에도 새 상담 버튼 제공 |

## 녹음 전 안내 모달 — 흐름 미리보기

- 실제 상담(LIVE)의 첫 녹음 시작 → 상담원 시작 문장·마이크 pulse 안내 → **이어서 녹음 시작** → 기존 마이크 입력 경로.
- 실제 화자 등록 기능이 아니다. 모달에서 녹음·전사·등록 요청을 하지 않으며 등록 완료를 표시하지 않는다. 안내 문장은 상담 기록에 넣지 않는다.
- 취소·닫기·ESC·배경 클릭은 마이크를 켜지 않는다. 같은 상담에서 녹음 재시작은 모달을 생략하고 새 상담에서는 다시 표시한다.
- 권한 오류 시 기존 오류 표시/재시도를 유지한다. TEXT·REPLAY·TRACE에는 모달을 적용하지 않는다.
- `scripts/speaker-intro-qa.cjs`: 12개 화면 크기, 포커스·취소·동작 축소, 권한 실패/재시도, 미리보기 중 오디오 전송 0건, 계속하기 후 PCM 전송, 중지/재시작·새 상담·연결 끊김 검증.

## 유지한 원칙

- 최초 흐름은 상담 준비 → 상담 시작 → 명시적인 녹음 시작이다. 마이크를 자동 활성화하지 않는다.
- 제외 사유 입력, 관리자 인증, 검수 승인, 진행 중 상담 종료 확인은 유지한다.
- 고객 발화·인용문·숫자를 프론트가 생성/수정하지 않는다. 기존 REST/WS 작업을 동일하게 호출한다.
- 스크롤로 항목을 감추지 않고 뷰포트 높이에 맞춘 페이지 목록을 유지한다. 자주 쓰는 버튼은 해당 항목 행에 배치한다.
- 큰 화면의 근거는 인용과 PDF를 나란히 보여준다. 작은 화면은 읽기 가능성을 위해 같은 창의 두 탭으로 전환한다.
- PDF 페이지 비율과 하이라이트 좌표를 유지한다. 뷰포트 전환만으로 같은 페이지 이미지를 반복 마운트하지 않는다.
- 기존 청록/하늘색과 Pretendard를 유지한다. 반복 안내 문구를 덜고, pulse는 조작 결과와 관련된 박스에 한정한다.

## 검증

- `scripts/final-feedback-qa.cjs`: 바로 재진술, 단일 근거창, 인용/PDF 동시 표시·비율, 모바일, 기록 출력·오류 피드백.
- `scripts/final-live-feedback-qa.cjs`: 실제 서버의 바로 실행 → 저장 확인 → 리포트 → 직접 TRACE → 설정을 유지한 새 상담.
- `scripts/final-admin-feedback-qa.cjs`: 실제 문서 전환·인증·추출 원문, 단일 셀 보기, 후보 편집·오류 재시도. 실제 승인 쓰기는 격리하여 실행하지 않음.
- `scripts/trace-source-qa.cjs`: 실제 저장 기록의 원본 선택, 단일 미리보기에서 재생, 원본 이벤트 보존.
- 결과와 화면 캡처는 `qa-output/`에 보관한다. 이전 서버 결함의 해결 여부와는 별개이며 [서비스 전체 상태](FINAL_IMPLEMENTATION_STATUS_20260905.md)의 백엔드 보류 항목은 유지한다.

최종 결과: 상담/근거/리포트 80개, 문서/표/편집 40개 크기·상태 검사 통과. TRACE 원본 선택과 미리보기 각각 10개 크기 검사 통과. 실제 TEXT 저장·리포트 직접 TRACE·새 상담 설정 유지와 타입/계약 검사 및 프로덕션 빌드(`.next-final-feedback-shallow-final`)도 통과했다. 상담 및 TRACE 검증 기록은 테스트로 새로 생성한 세션이며 원본 이력은 변경하지 않았다.
