# 말틈 제출 문서

- 기획서: `말해모해_말틈_기획서.pdf`와 같은 이름의 편집용 HTML
- 기능명세서: `말해모해_말틈_기능명세서.pdf`와 같은 이름의 편집용 HTML
- 도식 5종: `assets/diagrams/`의 HTML 원본·SVG·고해상도 PNG
- 제출 전 남은 작업: `내일_교체_체크리스트.md`
- 양식 원본은 상위 폴더에 그대로 보존했음

## 직접 편집

1. HTML을 Chrome 또는 Edge에서 열고 상단 ‘문구 편집’ 클릭
2. 본문을 직접 수정. 편집 모드에서 그림·촬영 안내 영역을 클릭하면 이미지 교체 가능
3. ‘수정본 HTML 저장’으로 저장한 뒤 새 파일을 열어 내용 확인
4. ‘PDF로 인쇄’ 클릭. A4·배율 100%·배경 그래픽 켜기·머리글과 바닥글 해제
5. 그림 교체 후 페이지가 늘어났는지 인쇄 미리보기에서 확인

이미지는 HTML 안에 포함돼 있어 다른 폴더로 옮겨도 문서를 열 수 있음. HTML 편집본을 직접 수정한 후 빌더를 다시 실행하면 그 변경은 덮어써지므로, 수정본은 별도 이름으로 보관해야 함.

## 도식 스타일

- 출처: https://github.com/cathrynlavery/diagram-design
- 기본 밝은 스타일만 사용(paper #f5f5f5 · ink #2d3142 · accent #eb6c36 · Geist / Geist Mono / Instrument Serif). 프로젝트 색상·Pretendard 적용 안 함
- 생성기: `assets/diagrams/build_diagrams.py`(HTML·SVG·manifest) → `render-diagrams.cjs`(Chrome 3배 PNG, 글자 넘침·겹침 검사). 도식을 고치려면 py 파일의 좌표를 바꾸고 두 스크립트를 순서대로 다시 실행한 뒤 `build_documents.py` → `render_documents.cjs`
- 한글은 Geist 에 글리프가 없어 시스템 글꼴(맑은 고딕)로 떨어짐. 영문·숫자·라벨만 Geist 계열
- 엔진 자료의 시스템 경계는 전체 구성도에, 판정 흐름은 엔진 도식에 배치. 모든 세부 구현을 독립 서버로 나열하지 않음

## 현재 남은 조건

- 화면 캡처는 요청에 따라 문서에 삽입하지 않고 촬영 안내만 배치했음
- 배포 URL·계정 필요 여부·최종 모델 구성·실서버 확인 결과는 입력 필요
- 현재 PDF는 위 안내가 남은 제출 준비본임. 안내를 검토·교체한 뒤 제출해야 함
- 독립 검토의 점수를 실제 심사 점수나 기능 검증의 증거로 사용하지 않음
