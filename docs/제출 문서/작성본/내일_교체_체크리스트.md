# 제출 전 교체 체크리스트

## 우선순위

1. 홈서버 배포 후 외부 네트워크·새 브라우저에서 실제 URL 접속
2. 기능명세서 5번의 URL·접속 조건·확인 시각과 최종 모델·실행 위치 기입
3. 아래 화면 촬영 후 HTML의 해당 그림 자리에 삽입
4. ‘배포 후’, ‘입력 필요’, ‘확인 필요’, ‘삽입 예정’, ‘미배포’, ‘촬영 안내’ 검색 후 실제 상태에 맞춰 갱신
5. HTML에서 PDF를 다시 출력한 뒤 전체 페이지 확인

공식 제출 마감: 2026-09-07 오전 10시. URL 접근 유지 기간: 2026-09-07 11시부터 2026-09-11 23시 59분까지. 출처: https://daker.ai/public/hackathons/2026-finance-ai-challenge

## 촬영 목록

| 위치 | 촬영 경로·조건 | 강조·자르기 | 확인 목적 |
|---|---|---|---|
| 기능명세서 2번 화면 1 | 첫 화면 → 상담 시작 → 상담 준비. 예금 최신 팩 선택 | 상품·팩 버전과 ‘상담 시작’ 버튼에 빨간 박스. 브라우저 탭과 불필요한 바탕 제외 | 시작 방법과 상담 기준 |
| 기능명세서 2번 화면 2 | 규정 관리 → 최신 규정 팩 → 중도해지 이자율 → 근거 원문 | 형광펜 구간과 앞뒤 문장을 확대. 페이지 번호·전체 페이지 버튼도 유지 | 인용 확인 후 주변 문맥까지 탐색 가능 |
| 기능명세서 3번 화면 3 | 예시 음원을 새로 처리하거나 음성 상담 실행. 확정 발화와 경보가 도착한 순간 | 대화·필수 안내·보완 안내에 ①②③과 빨간 박스. 전체 화면을 축소만 하지 말고 중요 영역 중심으로 잘라내기 | 입력과 판정의 연결 |
| 기능명세서 3번 화면 4 | 위 상담을 종료한 뒤 같은 세션의 종료 리포트 열기 | 팩 버전·경보 기록·PDF 저장 버튼 강조 | 상담과 종료 기록의 연결 |
| 기능명세서 5번 S1 | DEP-2026.08-v6에서 직원 ‘이자소득세는 14퍼센트입니다.’ 입력. 실서버에서 실제 처리 | 발화값 14%·기준값 15.4%·DEP-TAX-001 근거를 한 화면 또는 같은 세션의 연속 화면으로 구성 | 수치 오류와 원문 근거 검증 |
| 기능명세서 5번 S2 | S1과 같은 세션 종료 → PDF 저장 → 저장 파일 다시 열기 | 상담 버전·해당 경보·근거 항목을 잘라 확대 | 화면과 저장 결과 일치 |

S1을 텍스트 입력으로 실행하면 STT 검증이 아니므로 캡션에 ‘텍스트 입력’ 명시. STT까지 확인하려면 마이크나 예시 음원을 실제로 전사하는 실행을 추가해야 함. 기록 재생은 이미 저장된 결과를 보여주므로 새 추론의 증거로 사용하지 않음.

## 촬영 기록

- 화면마다 실행 일시, 팩 버전, 입력 방식, 상담 세션 식별값을 별도 기록
- 실측하지 않은 대기시간·정확도를 캡션에 넣지 않음
- 계정 비밀·토큰·실제 고객 개인정보·브라우저 개인 탭은 화면에서 제외
- 서버 주소가 포함된 화면은 공개 제출용 주소인지 확인
- 오류나 미완성 기능을 정상 결과처럼 보이도록 수정하지 않음. 빨간 박스·확대·개인정보 가림만 사용

## 배포 설정 확인

| 항목 | 확인할 내용 |
|---|---|
| 접속 | 제출 URL, HTTPS, 심사용 계정 필요 여부, 외부 접속 성공 시각 |
| STT | 공급자·모델·버전·실행 위치, 음원 입력부터 확정 전사 수신까지 |
| 화자 | 화자 분리 공급자와 역할 추정, 직원·고객 구분 |
| LLM | 공급자·모델, L3 활성 여부, 제한 시간, 첫 실행·반복 실행 지연 |
| 검색 | 임베딩 모델과 팩의 일치, 규정 질의 실제 답변 확인 |
| 저장 | PostgreSQL 사용 여부와 재시작 후 기록 보존, 예시 데이터 준비 |
| 범위 | LLM 보조 교정·생성 기본 비활성, 문서 본문 검색 기본 미연결을 실제 설정과 대조 |
| 유지 | 서비스·모델·DB 중단 감지와 담당자, 심사 접근 기간의 전원·네트워크 유지 |

## 제출 파일 확인

- 팀명 ‘말해모해’, 구성원 순서 ‘임한빈(팀장), 노순혁, 서재오, 허현준’ 유지
- 기획서 필수 1~6번과 자유 항목 7번, 기능명세서 1~5번 유지
- 실제 근거 없는 성능·보안·법적 보장 표현 추가 금지
- 문서 사진·도식 글자·페이지 번호·표 잘림 확인
- 두 PDF와 실행 가능한 URL을 각각 정해진 제출 항목에 등록
