## 최우선 지시

- 기획서와 기능명세서는 상위 폴더의 양식 PDF·HWPX를 기준으로 작성
- 팀명 말해모해. 임한빈(팀장), 노순혁, 서재오, 허현준 순서
- 개조식·음슴체. 문서에서 아직 구현되지 않은 기능을 현재 기능으로 표시하지 않음
- diagram-design은 https://github.com/cathrynlavery/diagram-design 의 기본 밝은 스타일만 사용
- 프로젝트 색상·Pretendard를 적용한 기존 도식은 사용자가 거절했음. 색상만 바꾸는 수준으로 끝내지 말고 기본 템플릿의 서체·여백·가느다란 선·정보 밀도로 다시 구성
- 화면 캡처는 최종 지시로 생략. 촬영할 화면·강조 영역·조건 설명만 유지
- 새 규정 문서 업로드 → 자동 룰팩 갱신은 MVP 제외
- 실제 홈서버는 아직 미배포. URL·모델 연결·실제 실행 성공을 지어내지 않음
- 사용자는 토큰 부족으로 지금 중단을 요청했음. 자동으로 재개하거나 추가 에이전트를 실행하지 않음
