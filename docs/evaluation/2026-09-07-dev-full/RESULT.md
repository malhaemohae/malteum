# 말틈 AI 기능 E2E 정답률 보고서

기획서의 AI 기능 다섯 가지(음성 인식·화자 구분, 관련 규정 검색, 상담 발화 재판정, 규정팩 구축, 수치 검증)에 대한 정답률 벤치마크 결과다. 2026년 9월 7일 `dev` 브랜치(병합 커밋 a3ee2bb) 기준이며, 원시 결과는 저장소 `docs/evaluation/2026-09-07-dev-full/`에 있다. 이전 기능 검증 자료 뒤에 이루어진 수정을 모두 반영한 최종 수치다. 이 문서는 그 뒤에 이루어진 수정을 모두 반영한 최종 수치다.

### 측정 조건

- 시나리오: 정기예금 상담 A·D, 신용대출 상담 B·C의 TTS 음원 4편을 각각 3회, 총 12회 실제 속도로 재생했다. 서로 다른 대본 줄은 68줄이고 반복을 포함하면 204줄, 확정 발화는 285건이다.
- 모델: 음성 인식 Qwen3-ASR-1.7B(로컬 GPU), 화자 분리 Sortformer streaming 4spk-v2(로컬 CPU), 검색 임베딩 multilingual-e5-small(로컬 CPU), 판정과 화자 역할 추론 Qwen3-8B(OpenRouter, temperature 0, 추론 모드 끔). 전사 교정 LLM과 답변 생성 LLM은 쓰지 않았다.
- 정답: 각 대본의 기대 요약과 줄별 기대 판정을 시험 전에 고정했다. 실행 결과에 맞추어 정답을 바꾸지 않았다.
- 실행: 정답률 측정에서는 L3 판정의 대기 제한을 30초로 두어 외부 API 지연이 결과에 섞이지 않게 했고, 3개 회차를 서로 다른 포트에서 동시에 돌렸다. 회차마다 새 서버 프로세스를 띄워 판정 캐시와 세션 상태가 비어 있다. 12회 모두 완주했고, 종료 뒤 이벤트 추가·이벤트 ID 중복·순번 중복은 없었으며 리포트 요약과 PDF 응답은 12회 모두 정상이었다.

- 숫자 오류 경보는 잘못 말한 값(예: 14%)과 기준값(15.4%)을 함께 보존해 발행했고, 값을 고쳐 쓴 경우는 없었다.
- 규정팩의 자동 폐기 2건은 원문에 없는 근거와 쪽 번호 불일치를 파이프라인이 잡는지 확인하는 부정 표본이다. 생성형 AI가 추출한 후보 자체의 정답률은 별도로 측정하지 않았다.

### 규정 검색률: 단계별과 통합

규정 검색은 L0 용어 정규화 → L1 규칙 대조 → L2 의미 검색 → L3 의미 재판정 순서로 좁혀 가며, 최종 상태는 네 단계의 결과를 합친 값이다. 단계별 수치는 같은 12회 실행의 판정 호출 기록에서 대본 줄별 기대와 대조해 계산했다.

| 단계 | 지표 | 결과 |
| --- | --- | ---: |
| L0 용어 정규화 | 상담원 발화에 든 팩 용어 77개 중 전사 직후 그대로 남은 비율 | 25/77, 32.5% |
| L0 용어 정규화 | 정규화 뒤 복원된 비율 | 74/77, 96.1% |
| L1 규칙 대조 | 규칙으로 판정해야 할 93건 중 항목 검출 | 87/93, 93.5% |
| L1 규칙 대조 | 같은 93건 중 상태까지 정확 | 84/93, 90.3% |
| L2 의미 검색 | L3 대상 발화 24건 중 정답 항목이 후보에 포함 | 21/24, 87.5% |
| L2 의미 검색 | 고객 되물음·금지 발언 의심 등 L2 잠정 판정 18건 | 18/18, 100% |
| L2 의미 검색 | 골든셋 29문장 recall@3 / top-1 (임베딩 단독) | 93.1% / 72.4% |
| L3 의미 재판정 | L3 대상 24건 중 상태와 누락 요소까지 정확 | 21/24, 87.5% |
| L3 의미 재판정 | 실제로 호출된 21건 기준 | 21/21, 100% |
| L3 의미 재판정 | 집중 검사(문장 35개 × 3회, 캐시 없음) 정답률 / 다른 항목 오인 | 96/105, 91.4% / 0건 |
| 통합 | 고지 항목 최종 상태 정답률 | 114/114, 100% |

- L1이 놓친 9건은 모두 뒤 단계에서 보완되어 최종 상태 오류로 이어지지 않았다. 상환방식 항목(B09)은 규칙 대신 L3가 부분 충족으로 판정했고, 예금자보호 항목(D09)은 규칙이 부분 충족으로 잡은 뒤 같은 상담의 뒷 발화에서 충족으로 갱신됐다.
- L3가 판정하지 못한 3건은 모두 고객이 지급제한 사유를 되짚는 발화(D14)로, 검색 단계가 후보를 만들지 못했다. 이 발화의 이해 확인 판정은 대본 기대에는 있지만 종료 요약 항목에는 들어가지 않아 통합 정답률에는 영향이 없다.
- L2 골든셋은 rulepack 모듈의 29문장(예금 13·대출 16, 무관 문장 8 포함)이다. 서비스 경로의 융합 검색으로 재면 recall@3 79.3%인데, 참고 문서 항목 4건이 검색 대상에서 빠지는 골든셋 구성 차이 때문이다.

### 처리 시간과 3초 대기 제한 운영 조건

정답률 측정(대기 30초, 3개 회차 동시 실행) 12회를 합친 처리 시간이다. 클라이언트 수신 시각은 WebSocket 도착 기준이다.

| 구간 | 표본 | p50 | p95 | 최대 |
| --- | ---: | ---: | ---: | ---: |
| 음성 구간 종료 → 확정 전사 도착 | 204 | 1.57초 | 2.12초 | 2.31초 |
| 규칙·검색 판정(L1·L2) | 285 | 8.6ms | 14.8ms | 164ms |
| L3 판정 호출 | 51 | 2.18초 | 3.08초 | 5.91초 |
| 발화 종료 → 판정 수신 | 147 | 1.90초 | 4.39초 | 7.43초 |

L3 호출 51건 중 6건이 3초를 넘겼고, 판정에 쓴 토큰은 115,381개다. 화자 역할 추론 토큰은 포함하지 않았다.

운영 기본값인 L3 대기 제한 3초로 같은 12회를 순차 실행한 결과는 다음과 같다. 대기 제한을 넘기면 규칙 단계의 잠정 판정을 유지한다.

| 지표 | 대기 3초(운영 기본값) |
| --- | ---: |
| 고지 항목 최종 상태 정답률 | 113/114, 99.1% |
| 금지 발언 위반 확정 정밀도 / 재현율 | 100% / 86.7% |
| 상담 종료 요약 완전 일치 | 10/12회 |
| 화자 역할 정답률 | 282/285, 98.9% |
| 경보 정밀도 / 재현율 | 100% / 100% |
| L3 대기 제한 초과 | 11/51건 |

초과 11건 중 8건은 한 회차에 몰렸고, 그 회차에서 위반 확정 2건이 의심 상태로 남고 화자 역할 오류 3건이 나왔다. 이 차이는 외부 API 지연에서 온 것으로, 판정 내용 자체는 대기 제한이 없을 때 전부 일치했다.

### 해석 범위

- 합성 음원 4편의 반복 결과이며 실제 창구 전체의 정확도나 동시 접속 처리량을 대표하지 않는다.
- 음성 인식과 검색은 로컬에서 실행했지만 판정은 외부 API를 거쳤으므로 완전한 내부망 구성의 결과는 아니다.
- 이벤트 저장소는 메모리이며 PostgreSQL 영속성과 재접속 복구는 이 측정에 포함하지 않았다.
- 실행 호스트는 i7-13700K와 RTX 4070 12GB이다.
