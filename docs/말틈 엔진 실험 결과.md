## 말틈 엔진 실험 결과

이 문서는 기획서에 첨부할 엔진 검증 자료다. [[말틈 엔진 전체 구성과 에이전트 역할]]과 [[말틈 에이전트별 담당 역할과 동작 과정]]에서 설명한 기능을 어떤 환경에서 시험했고 무엇을 확인했는지 제시한다. 실제 모델 호출, 저장된 전사문 비교, 모의 응답을 사용하는 기능 검사를 구분한다.

### 1. 판정 에이전트와 전체 상담 실행

#### 실험 구성

2026-09-05에는 예금·대출 상담 TTS 음원을 실제 속도로 재생해 음성 인식부터 상담 결과까지 연결했다. 음성 인식은 **로컬 Qwen3-ASR 1.7B**, 화자 분리는 로컬 Sortformer, 의미 검색은 로컬 multilingual-e5-small을 사용했다. 의미 판정과 화자 역할 판단에는 OpenRouter를 통해 Qwen3-8B를 호출했으며, 실시간 의미 판정의 대기 제한은 3초로 설정했다.

#### 실험 결과

| 검증 | 규모와 조건 | 확인한 결과 |
| --- | --- | --- |
| 예금 상담 전체 실행 | 약 147초의 TTS 음원 1개를 재생했다. | 설명 충족 4건, 부분 충족 1건, 미충족 1건, 위반 확정 1건, 경보 3건으로 대본의 기대 요약과 일치했다. |
| 대출 상담 전체 실행 | 약 128초의 TTS 음원 1개를 재생했다. | 설명 충족 5건, 부분 충족 0건, 미충족 2건, 위반 확정 2건, 경보 2건으로 대본의 기대 요약과 일치했다. |
| 8B 의미 판정 반복 비교 | 사례 4개를 각각 3회 실행하고, 숫자 처리 변경 전후를 비교했다. | 변경 전후 모두 기대 판정과 12/12 일치했다. 변경 후 응답시간 중앙값은 1.48초였다. |
| 기존 기능 회귀 검사 | 변경 전 487개, 변경 후 560개의 자동 검사가 통과했다. | 숫자 관련 검사 73개를 추가했으며, 기존 검사 실패는 없었다. 별도 2개 검사는 실행에서 제외됐다. |

반복 비교는 판정 내용과 누락 요건을 평가하기 위해 제한 시간을 넉넉하게 둔 실험이다. 변경 후 최대 응답시간은 3.94초였으므로, 12/12 일치를 “모든 요청이 3초 안에 성공했다”는 의미로 사용하지 않는다. 실제 TTS 실행에서는 8B의 판정 제한 시간 초과가 기록되지 않았다.

#### MVP 적용 범위와 내부망 운영 방향

실시간 판정은 **Qwen3-8B, 추론 모드 비활성화, 판정 대기 3초**를 기준으로 한다. 비교한 32B는 TTS 실행에서 제한 시간 초과가 9회 발생해 실시간 판정 후보에서 제외했다. 응답이 늦거나 실패하면 먼저 확보한 규칙 기반 결과를 유지한다.

이번 실험은 **음성 인식과 검색을 로컬에서 실행하면서도, 소형 언어모델을 연결해 두 상담 시나리오의 기대 결과를 얻었다**는 근거다. 최종 지향점은 언어모델까지 내부망에서 실행하는 구성이지만, 이번 판정은 외부 API를 사용했으므로 완전한 데이터 비유출이나 로컬 LLM의 처리 속도를 실증한 결과는 아니다. 또한 두 합성 음원과 반복 사례의 결과를 실제 창구 전체의 정확도로 일반화하지 않는다.

### 2. 전사 교정 기능 검증

| 검증 종류 | 확인한 내용 |
| --- | --- |
| 실제 LLM 연결 사례 | 2026-08-31 기록에서 “차감눌 → 차감률” 교정을 확인했다. 대규모 정확도 측정은 아니다. |
| 기존 자동 검사 재실행 | 2026-09-06에 용어 정규화·교정 관련 검사 10개를 실행해 모두 통과했다. 허용된 용어만 반영하는지, 정상 표현과 숫자를 보존하는지, 호출 실패 시 교정을 생략하는지 확인했다. |

자동 검사는 교정 기능의 처리 규칙을 확인하는 검사이며, LLM 응답은 모의 응답으로 대체했다. 실제 음성에서 발생하는 다양한 오인식에 대한 교정 정확도는 이 결과로 주장하지 않는다.

선택적 LLM 교정은 현재 확인한 구성에서 비활성화돼 있으며, 규칙 기반 용어 보완을 사용한다.

### 3. 규정 답변 기능 검증

상담 화면의 질문 입력부터 엔진의 답변 제공까지 연결돼 있다. 현재 확인된 MVP 구성에서는 **LLM 생성은 비활성화**돼 있으며, 승인된 설명과 검색 근거를 사용한다. 생성형 답변은 필요할 때 연결할 수 있는 선택적 기능이다.

2026-09-06에는 아래 항목을 포함한 기존 자동 검사 **3개를 재실행해 모두 통과**했다. 검색용 시험 자료와 모의 생성 응답을 사용해 기능의 동작을 확인했다.

| 검증 항목 | 입력 또는 조건 | 결과 |
| --- | --- | --- |
| 질문에 맞는 답변과 근거 | “중간에 깨면 이자가 어떻게 되나요?”를 질문했다. | 중도해지 관련 항목의 승인된 설명과 근거를 반환했다. |
| 무관한 질문 처리 | 주차장 여부와 점심시간 운영을 질문했다. | 규정 답변을 생성하지 않았다. |
| 근거 안의 생성 문장 | 검색 근거에 포함된 설명을 모의 생성 응답으로 제공했다. | 답변으로 채택했다. |
| 근거 밖 수치가 포함된 문장 | “중도해지하셔도 이자는 연 5.00% 그대로 드립니다”를 모의 응답으로 제공했다. | 답변을 거부했다. |

이 검증으로 관련 근거를 답변에 연결하고, 시험에 포함한 근거 밖 응답을 차단하는 동작을 확인했다. **실제 LLM을 이용한 질의응답 정확도나 평균 응답시간을 측정한 결과는 아니다.** 근거 대조만으로 모든 조건 해석이나 의미 오류를 탐지한다고 주장하지 않는다.

답변용 32B는 검토 중이며, 별도 연결과 실제 질의응답 정확도·응답시간의 검증을 완료한 상태는 아니다. 판정 실험의 정답률을 답변 성능으로 사용하지 않는다.

### 4. 공통 전사 처리의 숫자 해석·경보 개선

이 실험은 세 에이전트를 지원하는 숫자 처리 기능의 개선을 확인한다. LLM 용어 교정의 성능과 구분해 제시한다.

2026-09-05에는 Qwen3-ASR 0.6B·1.7B와 Nemotron으로 기존에 얻은 로컬 전사 자료 12벌을 재사용했다. 예금·대출 대본의 총 32줄을 각 구성에서 전사한 **384줄**이며, 같은 대본의 반복 자료다. 정답 화자를 부여하고 규칙·숫자 처리만 실행해 변경 전후를 비교했다.

| 숫자 해석·대조 지표 | 변경 전 | 변경 후 |
| --- | ---: | ---: |
| 세율·가정 금리의 값과 단위 추출 | 4/36 | 36/36 |
| 잘못 안내한 세율 14%의 경보 탐지 | 3/12 | 12/12 |
| 숫자 발화의 기대 경보와 결과 일치 | 63/72 | 72/72 |
| 정상 또는 비교 제외 발화에 잘못 발생한 경보 | 0/60 | 0/60 |

같은 자료를 서버의 처리 방식에 맞춰 669개 문장으로 나누어 재생했을 때도, 잘못된 세율의 경보 탐지는 **1/12에서 12/12로 개선**됐다. 기존 규정 판정의 누락은 발생하지 않았고, 숫자 표현을 새로 인식하면서 적절한 부분 충족 판정이 2건 추가됐다.

위 수치는 **로컬 전사 결과를 활용한 숫자 처리 개선 효과**이며, LLM 교정 모델의 정확도나 ASR 자체의 음성 인식률을 뜻하지 않는다.

추가 LLM 호출 없이 수치 표현과 분리된 문맥을 처리하도록 보완했다.

### 검증 범위 요약

판정은 실제 TTS 파이프라인과 반복 LLM 실험으로 확인했다. 전사 처리에서는 로컬 전사 자료의 숫자 해석·경보 개선을 비교했으며, 이를 LLM 교정의 정확도로 사용하지 않는다. 규정 답변은 근거 반환과 부적절한 응답 차단의 기능 검사를 통과했으며, 실제 생성 모델의 질의응답 정확도는 아직 측정하지 않았다.

2026-09-06에 재실행한 용어 교정 10개·규정 답변 3개 검사는 총 13개 모두 통과했다. 문서 본문 검색을 비운 시험 구성 등을 알리는 경고 8개가 있었으며, 이번 검사는 실제 문서 검색 전체나 실제 모델의 응답 품질을 검증한 것이 아니다.
